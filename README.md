### 🏟️ 서울시 공공체육시설 시각화
**2026.10 – 진행 중 | 팀 프로젝트**

서울시 공공체육시설 데이터를 활용하여 자치구별 시설 현황을 조회하고, 시설 유형에 따라 비교할 수 있는 웹서비스를 개발하는 프로젝트입니다. 사용자가 선택한 시설의 분포와 현황을 쉽게 파악할 수 있도록 하는 것이 목표입니다.
